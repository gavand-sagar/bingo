# BINGO

Multiplayer 5x5 number BINGO for phones. Create a room, share the 4-letter code or link, arrange your board, then take turns calling numbers. First to complete 5 lines (B-I-N-G-O) wins.

Static `index.html`; peer-to-peer via PeerJS/WebRTC (the room creator is the host).

Live: https://bingo-teal-eight.vercel.app
